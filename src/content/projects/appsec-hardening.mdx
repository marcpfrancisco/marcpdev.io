## Threats addressed

- SQL injection and cross-site scripting
- Session risks and unsafe file uploads
- Unauthorized access and API abuse
- Vulnerable dependencies and insecure configuration

## Controls put in place

- Protections against SQL injection, XSS, session risks and unsafe file uploads across company web applications.
- Role-based access control, API rate limiting and token-expiration controls.
- Hardened application configuration and audited npm dependencies.
- GitHub Actions CI/CD workflows, with improved pipeline security.
